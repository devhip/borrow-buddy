# Borrow Buddy

เว็บบันทึกของที่ให้เพื่อนยืม: ใครยืมอะไร เมื่อไร ต้องคืนเมื่อไร และกดว่าคืนแล้วได้
ขอบเขตและศัพท์ดูที่ [CONTEXT.md](CONTEXT.md)

## เริ่มใช้งาน
```
npm install
npm run dev       # เปิดดูตอนพัฒนา
npm test          # รันเทสต์ (Vitest)
npm run build     # สร้างไฟล์ใช้งานจริงที่ dist/
npm run preview   # เปิดดูไฟล์ที่ build แล้ว
```

## เทคโนโลยี
React + Vite + Tailwind CSS (JavaScript)

## ข้อมูลและการสำรอง
- ข้อมูลเก็บในเบราว์เซอร์ของเครื่องที่ใช้ (localStorage key `borrow-buddy:loans`) ไม่มีเซิร์ฟเวอร์
- หากล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง ข้อมูลจะหาย จึงควรกด "ส่งออกไฟล์สำรอง" เป็นระยะ
- กู้คืนด้วย "นำเข้าไฟล์สำรอง" (จะแทนที่ข้อมูลปัจจุบันทั้งหมด หลังกดยืนยัน)
